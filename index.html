Digital Piano

A polyphonic digital piano built on an STM32L432KC microcontroller with real-time audio synthesis and low-latency playback. The system generates piano tones entirely in firmware using additive synthesis with harmonics and ADSR envelopes.

  • 48 kHz DMA-driven DAC output with double buffering and analog RC filtering for clean audio at 5 ms latency
  • Polyphonic additive synthesizer using fixed-point phase accumulators and precomputed frequency steps for precise multi-note pitch control
  • ADSR envelope shaping per voice for realistic attack, sustain, and release behavior
  • RTOS task architecture separating key scanning, synthesis, and DAC output for deterministic timing

WiFi-Controlled RC Car with Speaker

Wi-Fi controlled robotic car built using an STM32L432KC and ESP32 with a Python client interface. The system separates networking and real-time control across two microcontrollers for responsive motor control and audio output while handling wireless communication.

  • Dual-microcontroller architecture: ESP32 handles Wi-Fi communication while STM32 performs real-time motor and audio control
  • Python client sends commands over a local Wi-Fi network hosted by the ESP32
  • Low-latency I²C communication between ESP32 and STM32 for command transfer
  • STM32 PWM motor control driving two DC motors through an H-bridge for speed and turning control
  • Sounds generated using STM32 DMA-driven DAC output connected to an amplifier and speaker

Snake Arcade Game (VHDL)

Final project for ES4: Digital Logic Circuits. A complete implementation of the arcade game Snake written in VHDL and deployed on an ICEUP5K (iCE40 UltraPlus) FPGA.

  • Snake game implemented entirely in VHDL on an FPGA, rendered over VGA (640×480) on a 16×16 grid
  • NES gamepad input with real-time score and high-score tracking
  • Custom pixel-art graphics for the snake, apple, start screen, and game-over screen
  • Finite state machine controlling movement, wall/self collision detection, tail updates, and RNG apple spawning
  • RAM game board encoding: snake body, apple, and background
  • Stable game tick and VGA timing derived from 12 MHz system clock

5-Stage Pipelined CPU

A 5-stage pipelined ARM-subset CPU implemented in SystemVerilog as a final project for EE25: Computer Organization. The processor executes a subset of the ARMv8 instruction set with full pipeline hazard handling.

  • 5-stage pipeline: Fetch, Decode, Execute, Memory, Writeback
  • Data hazard detection and forwarding unit to resolve RAW hazards without stalling when possible
  • Control hazard handling with branch prediction and pipeline flush on misprediction
  • Supports ALU instructions, load/store, and conditional branches
  • Tested on UPduino v3.0 FPGA with ModelSim simulation for verification

LiDAR View Synthesis

Undergraduate research project at the ASAR Lab, Tufts University, under Professor Jason Rife. Given two LiDAR frames captured from different positions, the goal is to synthesize what the scene looks like from the reference frame using data from a new frame, enabling comparison across arbitrary sensor poses. Performance is evaluated by computing RMSE between the synthesized and ground truth range images.

  • Built a full MATLAB benchmarking pipeline running 6 interpolation methods across 60-frame datasets with ICP pose registration
  • Methods compared: bilinear splatting with Gaussian hole filling, bilinear splat only, nearest neighbor, linear, triangle warp, and FFT lookup
  • Designed a novel FFT-based method evaluating fractional IDFT at pose-transformed reference pixel positions — eliminating scatter and gridding entirely
  • Results evaluated using RMSE, median error, 95th percentile error, and coverage vs pose distance
  • Data collected on Ouster OS2-128 (128x2048) from urban driving at Volpe National Transportation Systems Center
