Snake arcade game

Type
ES4, Digital Logic Circuits
Status
Complete

Final project for ES4: Digital Logic Circuits, built as a team. A complete implementation of the arcade game Snake written in VHDL and deployed on an ICEUP5K (iCE40 UltraPlus) FPGA. I worked mainly on the graphics, writing a Python script that converts pixel art into VHDL block ROM, implementing the sprites and the pattern generation for the VGA display, changing the ROM addressing to support the game grid, and contributing to the core game state logic.

  • Snake game implemented entirely in VHDL on an FPGA, rendered over VGA (640×480) on a 16×16 grid
  • NES gamepad input with real-time score and high-score tracking
  • Custom pixel-art graphics for the snake, apple, start screen, and game-over screen
  • Finite state machine controlling movement, wall/self collision detection, tail updates, and RNG apple spawning
  • RAM game board encoding: snake body, apple, and background
  • Stable game tick and VGA timing derived from 12 MHz system clock
